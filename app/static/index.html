Довідка

Про час

Усі розрахунки (impact, вікна T+1, T+5, T+15, T+30, T+60) ведуться в UTC — це стандарт для фінансових даних.

У веб-інтерфейсі час показується у Europe/Kyiv (EEST, UTC+3 улітку / UTC+2 узимку) для зручності, а UTC — у дужках поруч. Формат: 18:30 (15:30 UTC).

Що це за проєкт

Система моніторить економічні новини (ForexFactory), записує ціни SOL, BTC і ETH з Bybit у реальному часі та розраховує вплив кожної новини на ціну. Мета — знайти статистичні закономірності: чи реагують крипто-ринки на конкретні події передбачувано.

Основні терміни

Подія (Event)
Запланована публікація економічних даних (CPI, NFP, FOMC) або виступ чиновника. Має точний час в UTC.
Baseline (T-1)
Ціна за 1 хвилину ДО події. Від неї рахуються всі зміни.
Ret N хв (%)
Зміна ціни через N хвилин після події, у %.
Напрямок (Direction)
up — виросла більше порогу, down — впала більше порогу, flat — у межах порогу.
Очікуваний напрямок (Expected)
Куди "мала би" піти ціна на основі actual vs forecast. Наприклад: CPI вище прогнозу → hawkish Fed → очікується down.
Hit / Miss / Neutral / N/A / NO_DATA
HIT — очікуваний напрямок збігся з фактичним,
MISS — не збігся,
NEUTRAL — очікуваний або фактичний напрямок = flat,
N/A — немає expected через відсутнє правило,
— (NO_DATA) — взагалі немає forecast/actual (наприклад, виступи чи GDP/PCE, де ForexFactory не дає actual).
Hit Rate
HIT / (HIT + MISS) × 100. Показує, наскільки ринок реагує "логічно" на подію. NO_DATA і N/A не враховуються. n ≥ 20-30 для статистичної значущості.
Cross-asset / Excess
Порівняння реакції SOL, BTC, ETH на ту саму подію. Excess = Avg SOL − Avg BTC. Якщо близько 0 — SOL просто слідує за ринком, а не реагує самостійно.
LIVE-стрічка
Показує події в ±2 хв від поточного часу з цінами в реальному часі. Оновлюється кожні 2 секунди.

Як читати статистику

  • n < 10 — статистика ненадійна.
  • Hit Rate ≥ 60% на 30+ подіях — є статистична перевага.
  • Hit Rate ≈ 50% — новина не має передбачуваного впливу.
  • Avg +1хв великий, +15хв ≈ 0 — це шпилька (spike), заробити неможливо.
  • Cross-asset кореляція > 70% — SOL просто слідує за BTC.
  • Excess ≈ 0 — новина не рухає SOL окремо від загального ринку.

Джерела даних

  • Новини: ForexFactory (парсинг HTML).
  • Ціни: Bybit Spot API (WebSocket + REST).
  • Символи: SOLUSDT, BTCUSDT, ETHUSDT.
  • Комісії Bybit spot: Maker 0.1%, Taker 0.1%.
